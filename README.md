# Restaurant Data Analysis Using Python

## Project Overview

This project focuses on analyzing restaurant data using Python to extract meaningful insights related to restaurant ratings, votes, cuisines,
pricing, locations, online delivery, and table booking.

## Dataset

- Records: 9,542
- Columns: 21

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Workflow

1. Data Loading
2. Data Understanding
3. Data Cleaning
4. Missing Value Analysis
5. Duplicate Analysis
6. Statistical Analysis
7. Outlier Detection
8. Exploratory Data Analysis
9. Data Visualization
10. Business Insights
11. Conclusion

## Data Cleaning

- Checked missing values
- Handled missing values in the Cuisines column
- Checked duplicate records
- Examined data types
- Investigated potential outliers

## Analysis Performed

- Restaurant distribution by city
- Cuisine analysis
- Price range analysis
- Restaurant rating analysis
- Votes analysis
- Online delivery analysis
- Table booking analysis
- Average cost analysis
- Outlier analysis using IQR

## Key Findings

- The dataset contains 9,542 restaurant records.
- Restaurant ratings range from 0 to 4.9.
- The number of votes varies significantly between restaurants.
- Different price ranges were analyzed.
- Common cuisines and restaurant locations were identified.
- Online delivery and table booking availability were analyzed.
- Potential outliers were identified in cost and votes.

## Conclusion

This project demonstrates the use of Python for data cleaning,data manipulation, statistical analysis, exploratory data analysis,and data visualization. The analysis helped extract useful insightsfrom restaurant data and improved practical skills in Python anddata analytics.
